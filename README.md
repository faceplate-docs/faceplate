# FACEPLATE Documentation

Исходники документации платформы FACEPLATE (SCADA/EMS).

- [Документация на русском](docs/ru/README.md) — основной язык, пишется первым
- [Documentation in English](docs/en/README.md) — перевод утверждённых русских страниц

## Структура

```
docs/
  ru/                 основной язык
    overview/         обзор платформы, архитектура, глоссарий
    operator/         руководство оператора
    engineer/         руководство инженера проекта
    admin/            руководство администратора
    reference/        справочник: протоколы, история изменений
    assets/           изображения
  en/                 зеркало ru/ с теми же именами файлов
templates/            шаблоны страниц
CONTRIBUTING.md       правила написания
PLAN.md               план наполнения и статус страниц
```

Как писать и оформлять страницы — в [CONTRIBUTING.md](CONTRIBUTING.md).
