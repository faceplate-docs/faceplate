# Глоссарий

> Тип: справочник · Статус: черновик

Единые термины, которые используются во всей документации. Новый термин сначала добавляйте сюда, затем используйте в тексте.

| Термин | Определение |
|---|---|
| FACEPLATE (FP) | SCADA/EMS-платформа для сбора, хранения и обработки производственных данных. |
| Объект | Элемент дерева проекта с набором полей. Адресуется путём (path). |
| Путь (path) | Полный адрес объекта в дереве проекта. В интерфейсе отображается без префикса `/root/FP/PROJECT/`. |
| Поле | Именованное свойство объекта (например, `out_value`, `script`). |
| Прототип | Шаблон объекта: задаёт набор полей и серверную логику для всех объектов этого типа. |
| Схема (экран) | Веб-экран проекта: мнемосхема, таблица, форма. |
| Элемент схемы | Составная часть схемы: таблица (Grid), кнопка, график и т. п. |
| Архив | Объект, который сохраняет историю значений сигнала. |
| fp_ts | Хранилище временных рядов, где лежат точки архивов. |
| Тренд | График изменения значения сигнала во времени. |
| Серия | Одна линия на тренде: отображает один архив и имеет свои цвет, название и диапазон. |
| Группа трендов | Сохранённый набор серий, который открывается на тренде одним выбором. |
| Агрегат | Расчётная функция над значениями серии за период (среднее, минимум, интеграл и др.), выполняемая на тренде. |
| Тревога | Событие, требующее внимания оператора; квитируется. |
| fp-calculation | Системный объект для расчёта формул над сигналами. |
| graph_engine | Объект топологической раскраски электросхемы. |
| global_library | Папка проекта с общими JS-библиотеками фронта. |
| userlib | Пользовательские серверные модули на Erlang. |
| ПЛК | Программируемый логический контроллер. |
| АРМ | Автоматизированное рабочее место оператора. |
