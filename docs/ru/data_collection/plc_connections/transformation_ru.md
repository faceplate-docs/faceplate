# Преобразования PLC-привязок

[Каталог соединений](./index.md) · [Настройка привязки](./bindings_ru.md)

Faceplate v4.0.7. **Трансформация** обрабатывает значение между драйвером и полем проекта. Пустая цепочка не добавляет обработку; приведение к типу поля сохраняется.

## Направление и порядок

На чтении операции выполняются сверху вниз: внешнее значение → прямая цепочка → тип поля → поле. На записи: поле → выходное приведение типа → обратные операции в обратном порядке → драйвер. У серверов публикация W также использует обратную цепочку.

| Операция | Параметры | Чтение R/RW | Запись или публикация W/RW |
|---|---|---|---|
| Scaling | Factor 1, сдвиг 0; поле сдвига подписано Cмена | y = x × Factor + сдвиг | x = (y − сдвиг) / Factor; нужен ненулевой Factor |
| Default Value | Value 0 | Число сохраняется; нечисловой/отсутствующий вход заменяется Value | Пропускает значение |
| Limit Control | Lower Limit 0, Upper Limit 0 | Включительные границы; снаружи — отсутствие значения | Прижимает число к границе |
| Damper | Tlag 1 мс | Сглаживает; первое число проходит | Пропускает значение |
| Integration | Без параметров | Накопление входа × фактический интервал в мс; первый результат отсутствует | Не поддерживается |
| Derivative | Без параметров | Изменение / фактический интервал в мс; первый результат отсутствует | Не поддерживается |
| Скрипт | Erlang, контекст, состояние | Выполняет пользовательскую функцию | Не поддерживается |

Перед сохранением Limit Control задайте **Upper Limit > Lower Limit**; исходные 0/0 не образуют рабочую настройку. Для Damper требуется положительный Tlag. Integration и Derivative используют время обработки в миллисекундах: единицы результата — единицы входа × мс и единицы входа / мс. Состояние пересоздаётся при переинициализации; это не сохраняемый архивный итог.

## Настроить масштаб и проверить обе стороны

1. В R-привязке к float-полю добавьте **Scaling**. Введите Factor **0.1** и сдвиг **0**, завершите ввод Tab.
2. Сохраните, отдельно откройте привязку и проверьте **0.100000 / 0.000000**. При сохранившемся 1 исправьте уже сохранённый элемент и повторите проверку.
3. При внешнем 1000 ожидается поле **100.0**, при 1001 — **100.1**.
4. Если запись поддержана, задайте W/RW-поле **120.0**. Обратный масштаб даёт **1200**; подтвердите его независимым чтением.

Границы Limit Control относятся к тому этапу цепочки, где он установлен. Например, Scaling 0.1 перед Limit Control 0…150 проверяет инженерное значение. Default Value после отвергнутого входа может снова дать число.

## Написать Erlang-скрипт

Выберите **Доступ = R**, добавьте **Скрипт**. Функция принимает Input, Context и State и возвращает **{Output, State}**. Контекст — карта, ключи которой совпадают с колонкой **variable**; переменная связывается с **tag** и **field**. Начальное состояние — undefined.

Для масштаба и добавочного смещения задайте variable **Offset**, выберите подготовленный числовой тег смещения и его поле. Вставьте функцию:

    fun(Input, Context, State) ->
        Offset = maps:get("Offset", Context, 0),
        case is_number(Input) andalso is_number(Offset) of
            true -> {Input * 0.1 + Offset, State};
            false -> {none, State}
        end
    end.

Нажмите **Compile**, сохраните и повторно откройте привязку. При Input 1000 и Offset 2 ожидается **102.0**, при Input none — **none**. Compile подтверждает синтаксис; результат, ссылки контекста и новые входные данные проверяются отдельно.

Для нормализации входного Boolean в числовое 0/1 перед приведением к bool-полю можно использовать отдельную R-цепочку:

    fun(true, _Context, State) -> {1, State};
       (false, _Context, State) -> {0, State};
       (_, _Context, State) -> {none, State}
    end.

Проверьте оба состояния на источнике. Эта функция предназначена для входных true/false; числовые 0/1 относятся к другому представлению. Обратного преобразования у Script нет, поэтому W/RW с ним не настраиваются. Исполнитель этой PLC-трансформации — Erlang.

## Отсутствие данных и ошибки

Default Value может скрыть отсутствие связи правдоподобным числом; он заменяет нечисловой результат, но не является общим перехватчиком исключений. Ошибка прямой обработки может дать отсутствие значения при работающем транспорте. Ошибка обратной обработки не гарантирует подавления записи: проверяйте внешний результат.

Для W/RW все операции должны поддерживать обратное направление. При выборе Script, Integration или Derivative используйте R. Допустимая цепочка не добавляет отсутствующую у драйвера запись и не исправляет несовместимость String/Boolean автоматически.
