# IEC 62056 в Faceplate: настройка чтения и привязок

[Каталог](./index.md) · [Привязки](./bindings.md) · [Преобразования](./transformation.md) · [Диагностика](./diagnostics.md)

Faceplate v4.0.7 · Редакция 3 ноября 2026 года. Инструкция основана на исследованной реализации; приведённая конфигурация не объявляется проверенной через UI или обменом с прибором.

## Возможности и исходные данные

Faceplate инициирует обмен вида IEC 62056-21: идентификация прибора, переход в программный режим, передача пароля, запрос R1 и выход. Транспорт — TCP к совместимому шлюзу либо serial на узле выполнения Faceplate. DLMS/COSEM, серверная роль и запись параметров не реализованы. Для чтения выбирайте **R**; видимые W/RW не добавляют запись.

До настройки получите транспорт, адрес/порт или serial-параметры, буквальный address прибора, password, OBIS нужного числового параметра, формат ответа, единицы и множитель. Автоматического поиска приборов/OBIS нет. Для каждого параметра выполняется отдельный сеанс; несколько привязок увеличивают длительность полного обхода.

Подготовьте по [общей инструкции](./bindings.md#подготовить-тег-и-поле) папку **IEC62056_Training**, тег **MeterValue**, float-поле **value**, исходно 0.0. Параметры ниже иллюстративны; совместимый источник на 127.0.0.1:14000 не предполагается установленным.

## Создать соединение и полную привязку

| Объект | Поля примера |
|---|---|
| Соединение TrainingIEC62056 | Тип tcp; IP/Hostname/Localhost 127.0.0.1; Порт 14000; Период 1000 мс; timeout 1000 мс; attempts 3 |
| Общие настройки | Shutdown timeout 60000 мс; Главное соединение пусто; Отключено включено |
| Привязка Parameter1 | address 1; password 1; OBIS 1.8.0; Доступ R; Отключить включено |
| Назначение | /IEC62056_Training/MeterValue; поле value; Трансформация пустая |

1. В **Меню → Общий вид** откройте учебную папку, нажмите **Создать**, в группе **plc** выберите соединение IEC 62056.
2. Задайте TrainingIEC62056 и включите **Отключено** до сохранения. Заполните транспорт и числа из таблицы; завершайте ввод Tab.
3. Укажите timeout **1000** явно: в новой форме исходное 10000 превышает заданный ею предел 6000. Не используйте исходное значение как подтверждённую настройку.
4. Нажмите **save**, закройте и отдельно откройте объект через **Редактировать**. Сверьте значения и отключение.
5. Откройте соединение двойным щелчком и создайте Parameter1. Включите **Отключить**, задайте address, password и OBIS.
6. Выберите MeterValue у **тег**, затем отдельно поле **value**, R и пустую трансформацию.
7. Сохраните и отдельно откройте привязку. Сверьте всю строку назначения и буквальные реквизиты прибора.

Адрес прибора и OBIS передаются буквально; пример 1.8.0 не является подтверждением наличия этого параметра у любого счётчика. Пароль нужно заменить действительным. Одно соединение может содержать разные address/password, если это допускает линия.

## Настроить serial

Выберите **Тип serial**, задайте существующий порт узла, скорость, чётность, стоп-биты и размер байта по прибору. Исходные поля формы: /dev/tty0, 9600, нет, 1, 8; это не универсальные параметры линии.

После идентификации драйвер не перенастраивает скорость порта. Для прибора с изменением скорости после ACK нужен совместимый режим или шлюз и отдельная проверка. Сохраните отключённую конфигурацию и повторно откройте её перед рабочим запуском.

## Проверить число и единицы

Драйвер принимает числовое тело ответа между STX и ETX; единица после * отбрасывается. Например, числовая часть 230.1 даёт 230.1. Строки дат/времени, десятичная запятая, эхо или префикс OBIS перед скобкой могут не соответствовать ожидаемому формату.

Пустая трансформация передаёт число без назначения единиц. Если карта требует коэффициент 0.1, задайте Scaling 0.1/0: исходное 1000 должно дать 100.0. Множитель выбирается по карте, а не по имени OBIS.

Для рабочего запуска замените параметры реальными, разрешите нужные соединение/привязку и условия выполнения проекта. Сопоставьте новый ответ прибора с правильным полем. Общий RUN/OK не исключает ошибки отдельного OBIS.

## Параметры и длительность

| Поле | Исходное отображение / условие |
|---|---|
| Тип | tcp или serial; активен один транспорт |
| Порт TCP | В форме 1024; в модели 4000; вводите фактический порт явно |
| timeout | В форме 10000 при диапазоне 1–6000 мс; в примере явно 1000 |
| attempts | 3; диапазон формы 1–500; попытки отдельной транзакции |
| Период | 1000 мс; полный обход, а не обещанная частота каждого показания |
| Групповые PLC-запросы | Не реализованы; общий флаг, пакет и коэффициент не объединяют эти запросы |
| Ограничение памяти (байт) | Системное 1024; фактическая единица МиБ, вопреки подписи |

Сеанс включает несколько запросов, ожидание конца ответа и служебные паузы. Его длительность может значительно превышать Период. Начните с одного параметра, измерьте полный обход, затем расширяйте карту. Повышение периода не исправляет пароль или формат ответа.

## Изменение, резервирование и восстановление

Изменяйте канал через **Редактировать → save**, затем отдельно открывайте для сверки. **Отключено** относится ко всему соединению, **Отключить** — к одному параметру. Сохранённое старое число и Default Value не подтверждают связь.

[Альтернативный канал](./bindings.md#настроить-альтернативный-канал) использует привязки основного. Успешное открытие шлюза при неверном пароле/OBIS не гарантирует переключения.

## Диагностика

| Сообщение/симптом | Проверить и исправить | Подтвердить |
|---|---|---|
| econnrefused/timeout или ошибка serial | Адрес/порт с узла выполнения, путь порта и параметры линии | Открыт нужный канал и получен новый ответ |
| invalid_identification | Начало ответа, эхо и формат идентификации | Идентификация нужного прибора прошла |
| invalid_authentification_request | Поддержку программного режима и ответ P0 | Режим принят прибором |
| invalid_password | Пароль, адрес, полноту ответа и ожидание | Новый сеанс доступа прошёл; сообщение не всегда означает только неверный пароль |
| invalid_obis | OBIS, доступ и ответ R1 | Получен новый ответ параметра |
| no_block_start/no_block_end | STX/ETX, эхо, префикс и полноту кадра | Числовое тело разобрано |
| invalid_value | Числовой формат, точку и единицу после * | Ожидаемое число пришло в поле |
| RUN, но поле пустое/старое | Ошибку привязки, tag/field, преобразование и свежесть | Новое известное значение появилось в выбранном поле |

Откройте [общую диагностику](./diagnostics.md#собрать-журнал). Start/Stop относятся к журналу. После исправления получите новое B вместо прежнего A; при постоянном показании подтвердите новый успешный запрос/ответ. Работающий транспорт, снятая ошибка и старое число не заменяют эту проверку.
