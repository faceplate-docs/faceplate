# PLC-соединения: каталог и маршрут настройки

Faceplate v4.0.7 · Редакция 3 ноября 2026 года · Для интеграторов.

## Начать настройку

1. Выберите драйвер по интерфейсу устройства и роли Faceplate в таблице.
2. [Подготовьте тег и поле](./bindings.md#подготовить-тег-и-поле), затем откройте протокольную инструкцию.
3. Сохраните соединение и полную привязку отключёнными. Сверьте адрес, представление, направление, тег и поле.
4. Настройте [преобразование](./transformation.md), если карта требует масштаба или обработки.
5. После подготовки внешнего участника выполните [проверку нового значения и восстановления](./diagnostics.md).

Подробный [учебный пример Modbus TCP](./general.md) — дополнительный маршрут первого обмена. Для другого протокола используйте его инструкцию; общие задачи доступны по ссылкам выше.

## Выбрать соединение

«Запись» в таблице означает реальную операцию драйвера. Общие переключатели R/W/RW и группирования могут присутствовать и без соответствующей реализации.

| Инструкция | Роль и транспорт | Данные и направления | Групповые PLC-операции |
|---|---|---|---|
| [Modbus](./plc_modbus_connection.md) | Клиент; TCP, RTU-TCP, serial | Числовые/дискретные регистры; R/W/RW по области | Чтение; предел в байтах |
| [S7](./old_plc_s7_connection.md) | Клиент; TCP | I/Q/M/DB; bit/byte/word/dword; R/W/RW по адресу | Чтение; предел в байтах |
| [EtherNet/IP](./plc_ethernet_ip_connection.md) | Клиент; TCP | Скалярные переменные поддержанных CPU; R/W/RW | Чтение/запись; предел чтения — число переменных |
| [DCON](./plc_dcon_connection.md) | Опрос; TCP, serial | DI/AI: R; DO/AO: R/W/RW | Нет |
| [OPC DA](./plc_opcda_connection.md) | Клиент через TCP-прокси | ItemID; R/W/RW при совместимом прокси | Нет |
| [OPC UA — клиент](./old_plc_opcua_client_connection.md) | Клиент; opc.tcp | Скалярный BrowseName-путь; R/W/RW с ограничениями типов | Чтение/запись; предел чтения — число узлов |
| [OPC UA — сервер](./old_plc_opcua_server_connection.md) | Сервер; opc.tcp | W: публикация; R: приём; RW: оба, с ограничениями типов | Локальные чтение/запись; число узлов |
| [SNMP](./plc_snmp_connection.md) | Менеджер v2c; IPv4/UDP | Чтение числового OID; SET требует проверки сборки | Нет; GETBULK не включается |
| [M-Bus](./plc_mbus_connection.md) | Опрос; TCP, serial | Числовой блок телеграммы; только чтение | Нет |
| [Меркурий 230](./plc_mercury230_connection.md) | Опрос; TCP, serial | Накопленная энергия по тарифу; только чтение энергии | Нет |
| [IEC 62056](./plc_iec62056_connection.md) | Опрос; TCP, serial | Числовой параметр address/password/OBIS; только чтение | Нет |
| [IEC101 — клиент](./plc_iec101_client_connection.md) | Клиент; serial | Атрибуты IOA и команды; R/W/RW | Нет; Group request настраивается отдельно |
| [IEC101 — сервер](./plc_iec101_server_connection.md) | Сервер; serial | Публикация W, приём R, оба RW | Нет; Group broadcast отдельно |
| [IEC104 — клиент](./plc_iec104_client_connection.md) | Клиент; TCP | Атрибуты IOA и команды; R/W/RW | Нет; Group request отдельно |
| [IEC104 — сервер](./plc_iec104_server_connection.md) | Сервер; TCP | Публикация W, приём R, оба RW | Нет; Group broadcast отдельно |

Для OPC UA проверьте передачу Boolean/String, комплект сертификата и ключа и фактический режим защиты. У S7 проверьте доступность полей Slot/timeout в вашем редакторе. Для SNMP предварительно подтвердите SET на используемой сборке. Подробности и применимые проверки находятся в протокольных статьях.

У IEC 62056 реализован обмен вида IEC 62056-21 с числовым ответом; DLMS/COSEM и запись не предоставляются. У M-Bus и Mercury единицы и коэффициенты не назначаются автоматически.

## Как читать сведения о проверке

Сохранение и отдельное повторное открытие подтверждают конфигурацию. Обмен подтверждается новым результатом на принимающей стороне. Примеры оборудования и контрольные числа в новых пояснениях являются конфигурационными рецептами, если не указано выполненное испытание.

Целевая версия документации — Faceplate v4.0.7. Формы и снимки большинства статей проверялись в доступной Studio; это не подтверждение идентичности бинарной сборки исходникам. Даты и границы отдельных прогонов сохранены в материалах проверки; новая редакция текста не означает повторного аппаратного испытания.
