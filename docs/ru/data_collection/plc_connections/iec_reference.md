# IEC101/IEC104: типы, атрибуты и карта команды

[Каталог соединений](./index.md)

Faceplate v4.0.7. Справочник относится к клиентским и серверным соединениям IEC101/IEC104. Применимость направления определяется конкретной ролью: клиент читает удалённый кэш/отправляет команду, сервер публикует локальный объект/принимает команду.

## Выбрать Type и Parameter

Выбирайте информационный Type по карте устройства, затем явно выбирайте Parameter. Для каждого атрибута создавайте отдельную привязку с тем же IOA. У серверных привязок одного объекта согласуйте Type и Group. Наличие Value не создаёт автоматически поля качества и времени.

## Интерпретировать значение, качество и время

Single Point Value равен 0/1, Double Point — 0…3. Нормализованное измерение уже находится в −1…1; масштабируемое использует signed16, float — float32. Для масок и кодов выбирайте integer, для дробных измерений float.

QDS/SIQ/DIQ и другие дескрипторы — упакованные числа. Для Single Point маска качества QDS равна 254, для Double Point — 252. Плохое качество само по себе не блокирует Value. BCR содержит полные 40 бит, а Value счётчика — signed32.

TS с CP24 означает миллисекунды внутри часа; полной даты и часа в ней нет. TS с CP56 — Unix-время в миллисекундах с преобразованием через локальный часовой пояс узла. Для серверной отправки без явной CP56-метки может использоваться время кодирования старого значения. Метка не является универсальным признаком свежести.

## Пример: значение, качество и время одного IOA

Для источника с IOA 100 и Type 36: M_ME_TF_1 подготовьте Measurement.value типа float, Quality.value и Timestamp.value типа integer. Создайте три привязки: Address 100, Type 36, Parameter соответственно Value/QDS/TS, каждую со своим полем.

Клиенту задайте R; серверу для публикации W. Внешнее измерение 21.5 должно соответствовать Measurement.value=21.5 без преобразования. Качество и время проверяйте независимо; три отдельных обновления не являются атомарным снимком.

## Пример: команда и обратное состояние

Для клиента: базовые Address 101, Type 1, Parameter Value описывают обратное состояние; Доступ RW, Remote control type 45: C_SC_NA_1, Remote control address 200 — команду. Числовое задание 1 направляется на IOA 200; состояние читается с IOA 101.

Для сервера: Address 101, Type 1, Parameter Value, Доступ R, Remote control type 45 и Remote control address 200 задают приём команды в выбранное поле. Это перенос из серверной модели; для оборудования требуется отдельная выходная связь.

Командные пары без времени/с CP56: 45/58 — одиночная, 46/59 — двойная, 47/60 — шаговая, 48/61 — нормализованная уставка, 49/62 — signed16, 50/63 — float32, 51/64 — unsigned32.

Согласуйте прямую активацию и допустимые значения с внешней стороной. Отдельная подтверждённая семантика Select/Execute не предоставляется. ACTCON/ACTTERM и фактическая обратная связь — разные проверки. Это примеры конфигурации; новые команды данным справочником не объявляются испытанными.
