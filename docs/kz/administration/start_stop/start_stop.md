# Терминдер сөздігі

| Термин | Мағынасы |
|---|---|
| Түйін | FACEPLATE-тің іске қосылған бір сервері. Түйін атауы `fp@<сервер>` түрінде болады, [«Кластер түйіндері»](../nodes/nodes.md) қараңыз |
| Орнату каталогы | Серверде FACEPLATE орнатылған бума. Онда `bin`, `erts-<нұсқа>`, `etc`, `lib` және `releases` бумалары жатады. Бірінші іске қосудан кейін онда `logs` бумасы мен `DB` базасы, фонда іске қосқаннан кейін `log` бумасы, ал Git модулі репозиторийге қосылғаннан кейін `cvs` бумасы пайда болады |
| Түйін консолі | Жұмыс істеп тұрған түйіннің командалар орындалатын командалық жолы |

# Кіріспе

Түйін сервер терминалындағы командалармен (мысалы, SSH арқылы) іске қосылады және тоқтатылады. Командалар `faceplate` орнату каталогы жатқан бумадан орындалады. Командалардың толық тізімін параметрсіз `./faceplate/bin/faceplate` шығарады.

Түйін терминал терезесінде немесе фонда іске қосылады. Терезе жабылғанда түйінмен не болатыны және оның консолі қалай ашылатыны осыған байланысты.

# Негізгі бөлім

## Ашық файлдар шегі

Түйін процесіне кемінде 200 000 файл ашуға рұқсат етілгенде ғана жұмыс істейді. Шек іске қосар алдында сол терминалда `ulimit -n` командасымен беріледі:

```bash
ulimit -n <шек>
```

`<шек>` — 200 000-нан бастап сан. Команда тек осы терминалда әрекет етеді, сондықтан әр іске қосу алдында қайталанады.

Шек аз болса, түйін процесі іске қосылады, бірақ FACEPLATE жұмыс істемейді: Studio ашылмайды, ал `ulimit <ағымдағы> is less than minimum 200000` жолы `logs/console.log`, `logs/error.log` ішінде және іске қосу хабарламалары көрінетін жерде пайда болады: терминал терезесінде (терезеде іске қосу) немесе `log/erlang.log.<нөмір>` ішінде (фонда іске қосу). Түйінді тоқтатып ([«Тоқтату»](#тоқтату) қараңыз), шекті беріп, қайта іске қосыңыз.

## Терезеде және фонда іске қосу

| | Терезеде (`console`) | Фонда (`daemon`) |
|---|---|---|
| Іске қосу хабарламалары қайда көрінеді | Терминал терезесінде | Орнату каталогының `log/erlang.log.<нөмір>` файлында |
| Түйін консолі | Осы терезеде ашық | `remote_console` командасымен ашылады, [«Түйін консолі»](#түйін-консолі) қараңыз |
| Терминал терезесі немесе SSH сеансы жабылды | Түйін тоқтайды | Түйін жұмысын жалғастырады |

Іске қосудың кез келген тәсілінде қателер сервер журналдарына жазылады, [«Сервер журналдары»](../logs/logs.md) қараңыз.

## Терезеде іске қосу

```bash
ulimit -n <шек>
./faceplate/bin/faceplate console
```

Терезені түйін алады. Түйін жұмыс істеуі керек кезде оны жаппаңыз және SSH сеансын үзбеңіз.

## Фонда іске қосу

```bash
ulimit -n <шек>
./faceplate/bin/faceplate daemon
```

Команда терминалды бірден қайтарады, түйін фонда іске қосылады.

## Іске қосуды тексеру

Түйін іске қосылды, егер:

- терминал терезесінде (терезеде іске қосу) немесе `log/erlang.log.<нөмір>` ішінде (фонда іске қосу) `----------------FACEPLATE STARTED----------------------------` жолы пайда болса;
- Studio ашылса: `http://<сервер>:9000/fp/studio`.

`./faceplate/bin/faceplate ping` командасы түйін процесі жұмыс істесе `pong`, болмаса `Node is not running!` деп жауап береді. `pong` FACEPLATE жұмыс істейді дегенді әлі білдірмейді: ашық файлдар шегі аз болғанда да түйін `pong` деп жауап береді.

## Түйін консолі

Терезеде іске қосылған түйіннің консолі осы терезеде ашық. Фонда іске қосылған түйінге консоль басқа терминалдан қосылады:

```bash
./faceplate/bin/faceplate remote_console
```

Әр команда соңындағы нүктесімен толық енгізіліп, Enter басылады.

`remote_console`-дан түйінді тоқтатпай шығу үшін Ctrl+G басып, `q` енгізіп, Enter басыңыз. `q().` командасы түйіннің өзін тоқтатады.

## Тоқтату

```bash
./faceplate/bin/faceplate stop
```

Команда терезеде де, фонда да іске қосылған түйін үшін жұмыс істейді. Түйін терезеде іске қосылса, оны басқа терминалда орындаңыз. Команда түйін тоқтағанда аяқталады; осыдан кейін `ping` `Node is not running!` деп жауап береді.

## Кластерде іске қосу

Кластер түйіндері жеке түйін сияқты командалармен іске қосылады және тоқтатылады. Іске қосқанда айнымалы екі жағдайда қажет: түйін кластерге алғаш рет қосылады немесе кластер барлық түйін тоқтағаннан кейін іске қосылады. Бұл командалар алдында да [ашық файлдар шегі](#ашық-файлдар-шегі) беріледі. Түйіндер кластерге қосылуы үшін серверлерде нені баптау керектігін [«Қоймалар», «Серверлерді дайындау» бөлімінен](../../data_storage/storage/storage.md#серверлерді-дайындау) қараңыз.

### Түйінді кластерге қосу

Орнату каталогында `DB` бумасы бос түйін қосылады: жаңа орнату немесе `DB` бумасы жойылған түйін. Ол бірінші рет `ATTACH_TO` айнымалысымен — кластердің жұмыс істеп тұрған түйінінің атауымен іске қосылады:

```bash
ulimit -n <шек>
env ATTACH_TO=fp@<сервер> ./faceplate/bin/faceplate console
```

`fp@<сервер>` — кластерде жұмыс істеп тұрған түйіннің атауы. Түйінді фонда іске қосу үшін `console` орнына `daemon` жазылады. Түйін кластерге қосылып, оның базасымен жұмыс істейді. Айнымалы тек бірінші іске қосуда қажет: әрі қарай түйін әдеттегідей іске қосылады, [«Терезеде іске қосу»](#терезеде-іске-қосу) және [«Фонда іске қосу»](#фонда-іске-қосу) қараңыз. **Серверлер** панелі туралы [«Кластер түйіндері»](../nodes/nodes.md) қараңыз.

Түйіннің өз базасы бар болса, `ATTACH_TO` әсер етпейді: түйін өз базасымен бөлек кластер ретінде іске қосылады, қате туралы хабар болмайды. Сондықтан іске қосқаннан кейін түйіннің басқа түйіндердегі **Серверлер** панелінде көрінетінін тексеріңіз.

### Кластер толық тоқтағаннан кейін іске қосу

Кластердің барлық түйіні тоқтатылса, іске қосылғанда олар бір-бірін күтеді: олардың кез келгенінде басқаларында жоқ деректер болуы мүмкін. Бұл кезде `logs/console.log` ішінде `trying to connect to 'fp@<түйін>' node` және `There were active nodes ['fp@<түйін>'], when the node went down` жолдары қайталанады.

Кластер іске қосылуы үшін алдымен соңғы тоқтатылған түйін `FORCE_START` айнымалысымен іске қосылады. Ол түйінге басқаларын күтпей базаны ашуға рұқсат береді:

```bash
ulimit -n <шек>
env FORCE_START=true ./faceplate/bin/faceplate console
```

Фонда іске қосу үшін `console` орнына `daemon` жазылады. Осыдан кейін қалған түйіндер әдеттегідей іске қосылады, [«Терезеде іске қосу»](#терезеде-іске-қосу) және [«Фонда іске қосу»](#фонда-іске-қосу) қараңыз.

`FORCE_START` бір түйінге және тек осы іске қосуға беріледі. Осы айнымалысы бар түйін өз деректерін ең жаңа деп санайды, ал тек басқа түйіндерге түскен өзгерістер жоғалады. Ең жаңа деректер соңғы тоқтатылған түйінде болады, сондықтан айнымалыны сол алады.

# Қорытынды

Іске қосар алдында ашық файлдар шегі кемінде 200 000 етіп беріледі. Түйін терезеде (`console`) немесе фонда (`daemon`) іске қосылады: терезеде түйін терминал ашық тұрғанда жұмыс істейді, фонда — одан тәуелсіз. Іске қосуды `FACEPLATE STARTED` жолы мен ашылған Studio растайды. Жұмыс істеп тұрған түйіннің консолі `remote_console` арқылы ашылады, түйін `stop` командасымен тоқтатылады. Түйін кластерге алғаш рет `ATTACH_TO` арқылы іске қосылып қосылады, ал барлық түйін тоқтағаннан кейін алдымен соңғы тоқтатылған түйін `FORCE_START` айнымалысымен іске қосылады.
